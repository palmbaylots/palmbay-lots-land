# Content — automation output

Everything the Palm Bay automation produces lands here as reviewable files.
Subfolders are created on first use:

- `market-briefs/` — dated, sourced opportunity briefs from `palmbay-market-scout` / `opportunity-scout`
- `blog-drafts/` — publish-ready blog JSON from `palmbay-blog-writer`
- `listings/` — listing copy from `palmbay-listing-writer`
- `social/` — social post batches from `palmbay-social-content`
- `lead-followups/` — follow-up drafts from `palmbay-lead-followup`

These are drafts for human review. Nothing here is published, emailed, or posted
automatically — see `.claude/AUTOMATION.md` for the guardrails.
